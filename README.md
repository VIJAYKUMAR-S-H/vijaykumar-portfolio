# Vijaykumar Hadimani — Portfolio

A simple React + CSS developer portfolio. No Tailwind, no UI kit, no animation library and no complex state management.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- `public/profile.png` = profile photo
- `public/hackathon-proof.jpg` = Inno Hack Summit winning proof photo
- `public/resume-preview.png` = visual resume preview used by the View Resume modal
- The Resume button is **View only**; it does not expose a download CTA.
- Live Demo buttons are present for every project, but only become clickable after adding the real deployed URL in `src/main.jsx`. No fake demo URLs are used.
- Replace the generic LinkedIn/GitHub URLs with your actual profiles before publishing.
